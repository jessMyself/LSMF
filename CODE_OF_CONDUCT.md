# Code of Conduct

LSMF contributors are expected to keep collaboration safe, respectful, and
focused on evidence.

- Be constructive, specific, and considerate.
- Welcome questions and differing experience levels.
- Critique code and claims, not people.
- Do not publish private data, credentials, exploit details, or unsanitized
  system records.
- Respect the project's disposable-system and least-privilege boundaries.
- Stop harmful, harassing, discriminatory, or threatening conduct.

Maintainers may edit, hide, lock, or remove contributions and participation
that violate these expectations. Serious safety or security concerns should use
the private process in [SECURITY.md](SECURITY.md), not a public thread.
